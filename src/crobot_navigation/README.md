# crobot_navigation

This package contains implementations for autonomous robot behaviors and defines routines to be run by Behavior Tree.

## Nodes
- `crobot_navigation_node` - a node that starts a behavior tree from a specified routine

## Launch Files
- `rgbd.launch.py` - launches the SLAM process

## How To Use

### SLAM

The SLAM process can be launched in either a mapping or localization mode. The mapping mode is used for generating and saving maps created during a SLAM session. The localization mode is used for localizing the robot with respect to a premade map.

By default, SLAM launches in mapping mode. To start in localization mode, run:
```
ros2 launch crobot_navigation rgbd.launch.py localization:=true
```

When running with real hardware, disable the `use_sim_time` argument as shown below:
```
ros2 launch crobot_navigation rgbd.launch.py use_sim_time:=false [OTHER ARGUMENTS]
```

Additionally, QoS can be configured. The default QoS is 2, but can be set as shown in the example below:
```
ros2 launch crobot_navigation rgbd.launch.py qos:=1 [OTHER ARGUMENTS]
```

### Behavior Tree

The `crobot_navigation_node` loads and executes behavior trees. To run the node, run the following command:
```
ros2 run crobot_navigation crobot_navigation_node
```

Currently, a few behaviors have been designed to work with the crobot autonomy stack. The behaviors along with their expected parameters are described below:

- GoToPosition - sets nav2 goal position to the position specified by `goal_pose` and navigates robot to the goal position
    - parameters:
        - goal_pos: a list of numbers containing the goal pose of the robot formatted as "x, y, heading".

All behavior trees are loaded from the `trees` directory and `bt_default.xml` is executed when no tree is specified.
